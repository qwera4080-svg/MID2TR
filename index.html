Сократить расстояние между нотными блоками в раз


Как использовать:
1. Выбирте midi файл
2. Нажмите на кнопку «SAVE»
3. Откройте сохранённый файл с помощью импорта в редакторе TR
Внимание: файл может скачаться с расширением «.txt». В этом случае необходимо убрать расширение, переименовав файл в «out.trmap»
How to use:
1. Select the midi file
2. Click on the "SAVE" button
3. Open the saved file using import in the TR editor
Attention: the file can be downloaded with the ".txt" extension. In this case, you need to remove the extension by renaming the file to "out.trmap"
